## 📂 Projects Included

1. **The Pet Shop Website**
   - A responsive online pet store layout featuring pet care services, adoption listings, and interactive forms.
   
2. **Academy Cinemas**
   - A modern cinema hub using Bootstrap 5 grid layouts, movie schedule showtimes, and ticket reservation options.

3. **One-Page Website**
   - A single-page landing site with smooth scrolling navigation and an interactive JavaScript image Lightbox modal gallery.

4. **Simple Recipes**
   - An organized food and recipe showcase utilizing CSS Grid layouts for ingredients, prep instructions, and timers.

5. **Creating CSS Effects**
   - An experimental UI laboratory highlighting modern CSS keyframe animations, glassmorphism, and hover transformations.

6. **Pizza Menu**
   - A dynamic web ordering app that computes real-time price totals based on selected sizes and toppings.

7. **Tic-Tac-Toe Game**
   - A playable browser game built with JavaScript featuring win-detection logic, turn indicators, and game-reset functionality.

8. **Calculator**
   - A functional grid calculator that handles arithmetic operations, decimal inputs, and clear functions.
